ORBITAL v0.3.3

Start with NASA data

  1. Get your personal API key from NASA Open APIs.
  2. Extract the release ZIP. Save the key on a single line in API.txt beside launcher.py.
  3. Connect to the internet and run your Play-* launcher. Keep its terminal open.

The launcher opens the game after verifying the key and retrieving official data. If it stops, check the terminal message and try again.
